# 📅 Week-by-Week Schedule (July 6 – August 31, 2026)

~15–25 hours/week. It's summer — this leaves plenty of free time. The pattern: **mornings for building, one afternoon block for outreach, weekends mostly off.**

> Rule of thumb all summer: **every weekday, send 3 outreach messages or follow-ups.** Money comes from the boring repetition, not the code.

---

## Week 1 (Jul 6–12) — Setup + Portfolio 🏗️

**Goal: everything legal/financial ready, portfolio public. €0 earned and that's fine.**

- [ ] **Parent meeting (1 hour, Day 1).** Show them this plan. They need to: own the Claude account (and supervise its use), create the parent-owned Fiverr account, have/lend a PayPal, agree to sign client agreements. Checklist in [money-and-safety.md](money-and-safety.md).
- [ ] Bank: if 15+, open a free Slovak student account (Tatra banka / SLSP / VÚB / ČSOB — free for students); or Revolut <18 via parent.
- [ ] Get **GitHub Education** → free Copilot in your own name.
- [ ] **Polish both packs** (airdrop + SMP quests): test on latest Bedrock, clean READMEs with screenshots/GIFs, config sections documented.
- [ ] Publish both **free** on MCPEDL + CurseForge (parent-held account, join CurseForge Rewards). Push code to a public GitHub portfolio repo.
- [ ] Record two 60-second showcase clips (phone + screen record is fine). Post to YouTube.
- [ ] Join: Bedrock Add-Ons Discord, 2–3 hiring/freelance Discords (disboard.org → "hiring", "minecraft commissions"), make a BuiltByBit account (with parent permission).

## Week 2 (Jul 13–19) — Open for business 🟢

**Goal: all three pillars live. First tutoring student or first commission inquiry.**

- [ ] Fiverr gig live (template in [templates.md](templates.md)): *"I will create a custom Minecraft Bedrock behavior pack / addon"* — start cheap (€25–40 tier) to get first reviews, raise later.
- [ ] Post commission availability in Discord servers + BuiltByBit services forum (template ready).
- [ ] **Tutoring launch:** parents message their network + local Facebook groups: "learn to code / make Minecraft mods, €15–20/hr." Aim: 2 students booked.
- [ ] **Local website list:** 10 nearby businesses with bad/no websites. Pick the 3 where you have any personal connection.
- [ ] Build **one full demo site** for the best prospect (with Claude Code, an afternoon). Deploy free (Netlify/Vercel/GitHub Pages).

## Week 3 (Jul 20–26) — First money week 💶

**Goal: first paid work delivered.**

- [ ] Show demo site to prospect #1 — walk in with a parent, or through the family contact. Offer: €250 flat + €25/mo maintenance.
- [ ] Build demo #2 while waiting.
- [ ] Take **any** small commission (€20–40) even if underpriced — first reviews/vouches are worth more than the fee. Overdeliver, ask for a written review/vouch.
- [ ] Tutoring sessions running (prep once, reuse the lesson plan).
- [ ] Post 1 short clip (build timelapse / addon showcase).

## Weeks 4–5 (Jul 27 – Aug 9) — Find what's working 📈

**Goal: €200–€500 cumulative. Double down on whichever pillar is responding.**

- [ ] Raise commission prices after 2–3 vouches: small features €40–75, full packs €120–300.
- [ ] Close website #1 if not yet; pitch prospects #2–3 with their demos.
- [ ] Ask every finished client: *"Do you know one other person who needs this?"* — referrals are the whole game.
- [ ] Apply to contract for a **Marketplace partner studio** (Waypoint, Pathway — parent co-signs anything contractual).
- [ ] Keep the weekly clip going.
- [ ] **Mid-summer review:** rank pillars by €/hour so far. Kill or shrink the worst one.

## Weeks 6–7 (Aug 10–23) — Scale the winner 🚀

**Goal: €600–€1,500 cumulative.**

- If **commissions** are winning: raise prices again, take bigger custom-pack jobs (€200+), start a waitlist. Consider one polished free release to refill the funnel.
- If **websites** are winning: you have demos + referrals now — pitch 3 more businesses, push the €25–40/mo retainer hard on every close.
- If **tutoring** is winning: add students, or run a one-week "Minecraft modding mini-camp" for 4–6 kids (€50–80/kid = €200–480 in one week).
- [ ] One digital-product bet, max 2 days: package your best addon patterns as a documented template, or submit a Framer template.

## Week 8 (Aug 24–31) — Close out + set up the school-year money 🎓

**Goal: finish everything owed; convert summer work into passive/recurring.**

- [ ] Deliver all outstanding work (never carry client debt into the school year).
- [ ] Convert every website client to the monthly retainer — €25/mo × 4 clients = €100/mo *during school* for ~1h/month of work.
- [ ] Keep 1–2 tutoring students at a school-friendly schedule.
- [ ] Write down: total earned, €/hour per pillar, client list, vouches. That's next summer's head start — next year you start at Week 3 prices on Day 1.
- [ ] Long game check: portfolio now has published packs + real client work → exactly what the Marketplace Partner application (at 18) and studio contracting want.
